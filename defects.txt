# Defects Report: Flask Project Manager

## Defect 1: Missing Flask-SQLAlchemy in requirements.txt

**Severity:** CRITICAL

**Description:**
The `requirements.txt` file is missing `Flask-SQLAlchemy`, which is imported in `models.py` and used in `app.py`.

**Reproduction Steps:**
1. Follow the README onboarding instructions
2. Install dependencies: `pip install -r requirements.txt`
3. Run the Flask app: `flask --app app run --debug`

**Error Trace:**
```
ModuleNotFoundError: No module named 'flask_sqlalchemy'

Traceback (most recent call last):
  File "D:\bug_bash\1126\haiku\.venv\Lib\site-packages\flask\cli.py", line 219, in locate_app
    __import__(module_name)
  File "D:\bug_bash\1126\haiku\app.py", line 4, in <module>
    from models import db, Project, Task
  File "D:\bug_bash\1126\haiku\models.py", line 1, in <module>
    from flask_sqlalchemy import SQLAlchemy
ModuleNotFoundError: No module named 'flask_sqlalchemy'
```

**Fix:**
Add `Flask-SQLAlchemy==3.0.5` to requirements.txt

## Defect 2: Incorrect Environment Variable Name in README

**Severity:** HIGH

**Description:**
The README specifies setting `DATABASE_URL` environment variable:
```powershell
$env:DATABASE_URL = "sqlite:///project_manager.db"
```

However, the app.py code expects `DB_URL`:
```python
def init_database(flask_app: Flask) -> None:
    database_url = os.environ.get("DB_URL")
    if not database_url:
        raise RuntimeError("Missing DB_URL environment variable")
```

**Reproduction Steps:**
1. Follow README onboarding: `$env:DATABASE_URL = "sqlite:///project_manager.db"`
2. Try to run the app: `flask --app app run --debug`
3. App will crash with: `RuntimeError: Missing DB_URL environment variable`

**Error Trace:**
```
RuntimeError: Missing DB_URL environment variable
```

**Fix:**
Update README to use correct environment variable:
```powershell
$env:DB_URL = "sqlite:///project_manager.db"
```

## Defect 3: Incorrect API Request Payload in README Tutorial

**Severity:** HIGH

**Description:**
The README tutorial shows creating a project with `owner_email` field:
```python
payload = {
    "name": "Sample Project",
    "owner_email": "lead@example.com"
}
```

However, the app.py endpoint expects `owner` field:
```python
@app.route("/projects", methods=["POST"])
def create_project():
    payload = request.get_json(force=True)
    name = payload["name"]
    owner = payload["owner"]  # Expects "owner", not "owner_email"
```

**Reproduction Steps:**
1. Start the Flask app with correct DB_URL
2. Run the Python code from README tutorial
3. The request will fail with a KeyError

**Error Trace:**
```
KeyError: 'owner'
```

**Fix:**
Update README tutorial to use correct field name:
```python
payload = {
    "name": "Sample Project",
    "owner": "lead@example.com"
}
```

## Defect 4: Incorrect API Endpoint in README Tutorial

**Severity:** HIGH

**Description:**
The README shows listing tasks using endpoint `/api/projects/1/tasks`:
```python
response = requests.get("http://127.0.0.1:5000/api/projects/1/tasks")
```

However, the actual app.py endpoint is `/projects/<int:project_id>/tasks`:
```python
@app.route("/projects/<int:project_id>/tasks", methods=["GET"])
def list_tasks(project_id: int):
```

**Reproduction Steps:**
1. Start the Flask app
2. Create a project successfully
3. Run the command from README to list tasks
4. Receives 404 error

**Error Trace:**
```
HTTP Status: 404 Not Found
```

**Fix:**
Update README tutorial to use correct endpoint:
```python
response = requests.get("http://127.0.0.1:5000/projects/1/tasks")
```

## Defect 6: Missing Response Field in README Example

**Severity:** MEDIUM

**Description:**
The README example shows the expected response as:
```json
{"id": 1, "name": "Sample Project", "owner_email": "lead@example.com"}
```

However, the actual response contains `owner` not `owner_email`, and the endpoint returns HTTP 201 status:
```python
return jsonify({"id": project.id, "name": project.name, "owner": project.owner}), 201
```

**Reproduction Steps:**
1. Create a project with correct payload
2. Check response body - will have `owner`, not `owner_email`
3. Check status code - will be 201, not 200 (implied in docs)

**Fix:**
Update README expected response:
```json
{"id": 1, "name": "Sample Project", "owner": "lead@example.com"}
```
Also note the 201 Created status code.
